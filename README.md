# Статистика Авито

Бесплатная программа Александра Абрамова для разовой выгрузки статистики Авито.

Скачайте AvitoStats.exe в [последнем выпуске](../../releases/latest).
Windows x64; устанавливать Python не требуется. Можно вставить Client ID и
Client Secret либо загрузить список кабинетов CSV/XLSX. Ключи и отчёты
не передаются на GitHub.

Автообновление проверяет новые версии при запуске не чаще раза в 30 дней.
Новая версия проверяется по SHA-256 и устанавливается после закрытия программы.
В настройках можно отключить автообновление или проверить версию вручную.
Для проверки и скачивания обновлений программа обращается к GitHub;
GitHub получает обычные данные сетевого запроса, но не ключи Авито.

Это публичный канал выпусков. Исходный код и разработка находятся отдельно.
Существующие бесплатные функции описаны в каждом выпуске. Новые платные
функции, если они появятся, должны быть явно обозначены.
